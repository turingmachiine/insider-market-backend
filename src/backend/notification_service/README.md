# Notification Service

`notification_service` отвечает за live-обновления и пользовательские уведомления.

## Зона ответственности

- WebSocket/SSE-каналы для frontend.
- Live-обновления коэффициентов рынков.
- Уведомления о новых событиях, резолюциях и изменениях рейтинга.
- Доставка системных уведомлений пользователю.
- Подписка на внутренние события через Redis Pub/Sub или другой брокер.

## Возможные технологии

- FastAPI WebSocket или SSE.
- Redis Pub/Sub на первом этапе.
- NATS или Kafka при росте нагрузки и требований к гарантированной доставке.

## Границы сервиса

- Сервис не владеет рынками, событиями, рейтингами или профилями.
- Он доставляет изменения, полученные от `market_service`, `event_service`,
  `rating_service` и `profile_service`.
