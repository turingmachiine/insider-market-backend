# Profile Service

`profile_service` отвечает за публичные и социальные данные пользователя.

## Зона ответственности

- Публичный профиль пользователя.
- Пользовательские настройки профиля.
- Баланс пользователя в виртуальной валюте для будущих игровых сценариев и
  ставок в `market_service`.
- История операций по балансу.
- История активности пользователя.
- Подписки на других пользователей.
- Социальные связи и списки наблюдения.
- Витрина достижений пользователя.
- Связь профиля с рейтингами и игровой активностью.

## Границы с другими сервисами

- Учетные данные, пароль, роли и permissions находятся в `auth_service`.
- Расчет рейтингов находится в `rating_service`.
- Выдача достижений может рассчитываться в `rating_service` или отдельной
  доменной логике, но отображение и пользовательская витрина принадлежат
  `profile_service`.

## Текущий статус

Реализован базовый backend-срез сервиса:

- доменная модель профиля, баланса, операций, активности и достижений;
- SQLAlchemy imperative mapping и репозитории;
- Dishka DI-контейнер;
- FastAPI API `/api/v1/profiles`;
- Alembic-миграция `001_initial_profile`;
- unit и integration тесты.
