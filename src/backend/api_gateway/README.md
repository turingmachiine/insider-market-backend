# API Gateway

`api_gateway` — единая публичная точка входа в backend Insider Market.

## Зона ответственности

- Принимать внешние HTTP-запросы от frontend, админки и внешних клиентов.
- Проксировать запросы во внутренние backend-сервисы.
- Применять общие middleware: CORS, security headers, request logging, rate limit.
- Передавать identity-контекст пользователя во внутренние сервисы.
- Агрегировать сервисную документацию и health-check endpoints.

## Что не входит в сервис

- Бизнес-логика рынков, событий, профилей, рейтингов и справочников.
- Прямой доступ к доменным таблицам внутренних сервисов.
- Самостоятельная проверка сложных прав доступа вне общих gateway-политик.

## Текущий статус

Сервис уже существует и используется в Docker Compose как публичный backend endpoint
на порту `8000`.
