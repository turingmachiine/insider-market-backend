# Market Service

`market_service` отвечает за Prediction Market и AMM.

## Зона ответственности

- Создание рынков для активных событий.
- Прием пользовательских ставок виртуальными токенами.
- Расчет коэффициентов после каждой ставки.
- Хранение сделок, позиций пользователя и состояния ликвидности.
- Публикация live-изменений коэффициентов для `notification_service`.
- Закрытие рынков после резолюции события.

## Возможные технологии

- FastAPI для HTTP API.
- PostgreSQL для рынков, ставок и позиций.
- Redis для кэша актуальных коэффициентов и публикации live-событий.

## Границы сервиса

- `market_service` не решает, правда событие или нет; итоговый outcome приходит
  из `event_service`.
- Рейтинги пользователей рассчитывает `rating_service`.
- Профиль пользователя хранится в `profile_service`.
