# Admin Service

`admin_service` отвечает за административные сценарии Insider Market.

## Зона ответственности

- Backend-for-frontend для административной панели.
- Агрегация данных для модерации слухов и событий.
- Операционные сценарии: approve, reject, resolve, cancel, adjust source weight.
- Представления для мониторинга проблемных событий и ошибок обработки.
- Координация запросов к `rumor_service`, `event_service`, `nsi_service`,
  `market_service` и `auth_service`.

## Границы сервиса

- Сервис не должен владеть доменными моделями слухов, событий, рынков или
  пользователей.
- Сложные изменения должны выполняться через API профильных сервисов.
- Проверка ролей и permissions должна опираться на `auth_service`.
