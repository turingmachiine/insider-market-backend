# NSI Service

`nsi_service` — сервис футбольной справочной и аналитической информации.

NSI здесь означает normalized/sport information layer: игроки, клубы, лиги,
команды, статистика и расчетные аналитические представления.

## Зона ответственности

- Хранение и выдача справочников игроков, клубов, лиг и команд.
- Работа с футбольной статистикой, матчами, трансферами и метриками игроков.
- Расчет radar charts.
- Поиск похожих игроков.
- Подбор shadow-team кандидатов для усиления состава.
- Интеграции с внешними спортивными API на уровне футбольных данных.

## Границы с другими сервисами

- Слухи, инсайды и публикации источников относятся к `rumor_service`.
- События prediction market относятся к `event_service`.
- Ставки, коэффициенты и AMM относятся к `market_service`.
- Рейтинги пользователей относятся к `rating_service`.

## Текущий статус

Сервис уже существует и является основным примером структуры для новых
backend-сервисов: `domain`, `application`, `infrastructure`, `processing`,
`presentation`, SQLAlchemy table definitions и Dishka providers.
