# Auth Service

`auth_service` отвечает за учетные записи, аутентификацию и авторизацию.

## Зона ответственности

- Регистрация и аутентификация пользователей.
- Выпуск и проверка JWT.
- Управление ролями и permissions.
- Хранение учетных данных и служебных данных авторизации.
- Кэширование прав доступа, когда это необходимо для быстрых проверок.

## Границы с другими сервисами

- Публичный профиль пользователя, достижения и подписки относятся к
  `profile_service`.
- Игровые рейтинги и лидерборды относятся к `rating_service`.
- Административные рабочие сценарии относятся к `admin_service`, но используют
  роли и permissions из `auth_service`.

## Текущий статус

Сервис уже существует, имеет отдельную базу PostgreSQL, миграции и DI-настройку.
Дальнейшее развитие должно сохранять структуру, близкую к `nsi_service`.
